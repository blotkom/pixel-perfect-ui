# Pixel Perfect UI

Recreate this UI pixel-identically from the reference image. Match the layout, dimensions, spacing, typography, colors, borders, shadows, icons, alignment, and every visible detail exactly. Do not redesign, reinterpret, simplify, or add anything. The final implementation must be visually identical to the reference image at the same viewport size.

Treat the reference image as the single source of truth. Implement the screen to be pixel-identical to it, with no creative interpretation or design changes.
